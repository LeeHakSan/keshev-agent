## 4. 13~21단계 기능 · 결과 · 근거 · 미확인

범례: **모의** = 가짜 DOM 으로 입력을 바꿔 가며 확인한 임시 점검(저장소 밖). **예제 화면** = `npm run demo` 의 예제 자료를 브라우저에서 본 것(실제 시스템 연결이 아님). **실제 연결** = 실제 연동 시스템·AI·OSV 로 확인한 것. 이 프로젝트에서 **실제 연결로 확인한 항목은 없습니다.**
"포털 판정"은 학생이 포털에서 보고 알려 준 것을 옮긴 진술이며, 각 단계 제출 커밋에서의 결과입니다.

## 5. 데이터 보존 계획

**보존할 대상**

| 대상 | 위치 | 설명 |
|---|---|---|
| 학생이 작성한 코드 | `student/extension.mjs` | 이 프로젝트에서 학생이 만든 유일한 코드 파일 |
| 학생 문서 | `docs/STUDENT_RUNBOOK.md`, `docs/STUDENT_RELEASE_RECORD.md` | 실행 설명서와 이 기록 |
| 변경 이력 | Git 기록 (`.git`) | 단계별 커밋 |
| 설정 견본 | `.env.example` | 비밀 없는 설정 예시 |

**보존하지 않거나 이 저장소에 없는 것 (제한)**

- 앱 실행 중의 화면 상태는 서버·브라우저 메모리에만 있고 파일로 저장되지 않습니다. 코드를 읽은 범위에서 학생 코드와 `public/app.js` 는 `localStorage`·파일 저장을 쓰지 않습니다. 서버를 다시 켜면 처음 상태가 됩니다.
- 조치 기록용 SQLite 데이터베이스는 신뢰된 호스트가 설정 파일로 명시했을 때만 쓰이고(`src/actions/README.md`), 기본 실행에서는 만들지 않습니다. 이 프로젝트에서는 설정하지 않았습니다.
- 키·토큰·비밀번호·`.env` 는 저장소에 넣지 않으며 백업 대상에도 포함하지 않습니다. 이 저장소에는 `.gitignore` 가 없으므로 `.env` 를 만들면 커밋하지 않도록 직접 주의해야 합니다(7장).
- 커밋하지 않은 변경, 저장소 밖 임시 점검 스크립트(`/tmp`), 외부 서비스(AI 게이트웨이·OSV·연동 시스템)에 있는 데이터는 이 계획의 보존 대상이 아닙니다.

**백업**

1. 변경을 커밋하고 `git push origin main` 으로 GitHub 에 올립니다. (원격과 로컬이 같은지 `git rev-list --left-right --count HEAD...origin/main` 이 `0	0` 인지 확인)
2. 추가 사본이 필요하면 저장소 폴더 안에서 `git bundle create <저장소 밖 폴더>/keshev.bundle --all` 로 한 파일에 담습니다.

**복원**

1. GitHub 에서: `git clone https://github.com/LeeHakSan/keshev-agent.git` 후 `git checkout --detach <40자리 커밋>`.
2. 번들에서: `git clone <번들 파일> <새 폴더>` 후 같은 방식으로 커밋을 선택합니다.
3. 복원 후 `docs/STUDENT_RUNBOOK.md` 4장의 절차로 실행합니다.

확인한 것: 위 번들 백업·복원을 실제로 해 보았습니다(2026-10-25). 번들 검증이 통과했고, 번들에서 복원해 같은 커밋(`43c911a…`)을 선택하자 `student/extension.mjs` 가 원래 파일과 동일했습니다. GitHub 에서 `git clone` 복원도 3장에서 확인했습니다. **미확인:** Windows 에서의 백업·복원, 비공개 저장소 전환 뒤의 복원.

## 6. 이동 가능성 (다른 PC 로 옮길 때)

- 필요한 것은 저장소 전체와 Node.js 입니다. 외부 npm 의존성이 없어 설치 단계가 없고, 설정 견본은 `.env.example` 입니다.
- 저장소 안의 문서·코드에 이 PC 의 절대경로나 비밀값을 고정하지 않았습니다. 실행 위치는 `<저장소 폴더>/on-client` 로 표기합니다.
- 기존 폴더의 인증·설정 파일을 복사하지 않아도 3장처럼 예제(demo) 실행이 되었습니다. 실제 연결에 필요한 계정·앱 권한·연결 설정은 운영자와 신뢰된 호스트가 준비하는 것이며 저장소에 없습니다.

## 7. 지원 범위 · 누락 · 미해결

- **지원 범위(확인한 것):** macOS, Node.js v24.22.0, npm 11.19.1, Chrome, 예제(demo) 실행과 기본 실행(연결 없음 상태). 그 밖의 환경은 확인하지 않았습니다.

- **실제 연동 시스템(`connected`)·AI 연결 성공·AI 사건 설명 성공·OSV 패키지 표:** 실제 연결로 확인하지 못했습니다(4장).

- **1280px 이상 넓은 화면 배치:** 확인한 브라우저 창 너비가 약 855px 이었습니다.
- **22단계 판정:** 아직 받지 않았습니다. 판정에 통과해도 원문 검토 기준의 수료이며, 실제 운영 인증이나 v1.0 인증이 아닙니다.
